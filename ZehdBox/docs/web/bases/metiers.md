# <span class="h1">Les métiers du Web</span>

<p class="intro">
    Le web emploie de nombreux professionnels aux compétences complémentaires.
    Découvrez les principaux métiers.
</p>

---

## <span class="h2">Vue d'ensemble</span>

| Métier | Langages / Outils | Focus |
|--------|-------------------|-------|
| :material-language-html5: **Frontend** | HTML, CSS, JavaScript, React | Visuel et UX |
| :material-server: **Backend** | Python, PHP, Java, SQL | Logique et données |
| :material-account-group: **Full Stack** | Tous les above | Polyvalent |
| :material-bug: **QA** | Selenium, Jest | Qualité et tests |
| :material-server-network: **SysAdmin** | Linux, Docker, CI/CD | Serveurs et infra |

!!! tip "Full Stack"
    Le développeur **Full Stack** combine les compétences **Frontend** + **Backend** + **Infrastructure**.
    C'est le profil le plus polyvalent, mais aussi le plus large à maîtriser.

---

## <span class="h2">Les métiers en détail</span>

### Développeur Frontend

!!! example "Rôle"
    Il crée la **partie visible** du site web : le design, les animations,
    l'expérience utilisateur.

| Compétences | Outils |
|-------------|--------|
| HTML, CSS, JavaScript | React, Vue.js, Angular |
| Responsive design | Figma, Bootstrap |
| Accessibilité (a11y) | Lighthouse, axe |

---

### Développeur Backend

!!! example "Rôle"
    Il crée la **logique** du site : authentification, bases de données,
    API, règles métier.

| Compétences | Outils |
|-------------|--------|
| PHP, Python, Java, Ruby, C# | Django, Symfony, Spring |
| Bases de données (SQL) | MySQL, PostgreSQL |
| API REST / GraphQL | Postman, Swagger |

---

### Développeur Full Stack

!!! tip "Le couteau suisse"
    Le développeur **Full Stack** maîtrise les deux côtés :
    frontend **et** backend, et parfois aussi l'infrastructure.

C'est le profil le plus polyvalent, mais aussi le plus difficile à
maîtriser car il couvre un très large champ de compétences.

---

### QA Manager (Quality Assurance)

!!! example "Rôle"
    Il **teste** le site pour détecter les bugs, les erreurs d'affichage,
    les problèmes de performance et d'accessibilité.

| Compétences | Outils |
|-------------|--------|
| Tests manuels et automatisés | Selenium, Jest |
| Recette fonctionnelle | Jira, TestRail |
| Performance | Lighthouse, JMeter |

---

### SysAdmin (Administrateur Système)

!!! example "Rôle"
    Il **crée et configure les serveurs**, gère l'hébergement,
    la sécurité et le déploiement des sites.

| Compétences | Outils |
|-------------|--------|
| Linux, réseaux, sécurité | Docker, Kubernetes |
| CI/CD | GitHub Actions, GitLab CI |
| Monitoring | Grafana, Prometheus |

---

!!! info "Et après ?"
    Ces métiers évoluent constamment. De nouveaux profils apparaissent :
    **DevOps** (mélange SysAdmin + développement), **Data Engineer**,
    **Cloud Architect**... Le web est un domaine en perpétuelle mutation.
