### 1. Déclarer une variable

En informatique, une variable est un conteneur qui stocke des données temporairement au sein de notre code.

Différents types de variables :

- **`number`**: la donnée est un chiffre
- **`string`**: la donnée est une chaîne de caractères
- **`boolean`**: la donnée est vraie ou fausse

Pour déclarer une variable, nous utilisons une ***instruction***.

!!! note "Note"
    Les instructions sont des mots clés uniques qui permettent au code d'être exécuté.
    Pour déclarer des variables, nous utilisons les instructions ***`let`*** et ***`const`***.

***Instruction `let`*** :

Permet de déclarer une variable. Elle permet aussi de la redéfinir sans réécrire l'instruction ***`let`.***

***Instruction `const`*** :

Permet aussi de déclarer une variable.
Cependant `const` est une constante, c'est-à-dire qu'une fois déclarée, elle ne peut/doit plus être changée. Si l'on essaie, JavaScript refusera d'exécuter l'instruction et affichera une erreur.

!!! note "Note"
    L'instruction ***`var`*** peut aussi être utilisée pour déclarer une variable. Cependant elle est devenue obsolète.

***Instruction `console.log`***

Permet de vérifier le contenu d'une variable en l'affichant dans le terminal
